# Encore · Artist Booking

A responsive static website concept for discovering and booking South African artists, DJs, vocalists, bands and event hosts.

## Live demo
Once GitHub Pages finishes deploying: https://lungaowen.github.io/artist-booking-studio/

## Features
- Responsive landing page and artist cards
- Search by artist name, style or vibe
- Filter by talent category and South African city
- Save artists to a local in-page shortlist
- Booking enquiry form that prepares an email draft
- Newsletter and sign-in demo interactions
- Accessible labels, dialog form and reduced-motion support
- Plain HTML, CSS and JavaScript; no build step or backend required

## Run locally
Open `index.html` in a browser, or serve the directory with any static web server.

## Important demo notes
This is a front-end prototype. Artist profiles, pricing, ratings and availability are sample content. Booking requests are not stored or confirmed, there is no payment processing, and newsletter/sign-in actions are demo interactions. Replace the `hello@encore.example` address with a real contact address before launch.

Artist photography is loaded from Unsplash; Google Fonts are loaded from Google Fonts. These require an internet connection.

## Hosting
GitHub Pages publishes the root directory from the `main` branch. No secrets or environment variables are needed.
